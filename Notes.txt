repository Storage in B2

      Step 17 — Do NOT upload the user's entire project as one B2 file

            This is important.
            Don't do:

            hello-world.zip

            for your Git storage architecture.

            Instead:

            Git repository
                  │
                  ├── objects
                  ├── refs
                  └── HEAD

            That allows us to eventually transfer only the objects that are missing.

            For example:

            Local has: A B C
            Remote has: A B
            Push: only C

            That's the basic idea behind efficient Git-like synchronization.
